# Portofolio
My Personal Portfolio Website

## 🛠️ Teknologi yang Digunakan

- **HTML5** - Struktur semantic
- **CSS3** - Styling dengan fitur modern (Gradients, Animations, Flexbox, Grid)
- **JavaScript (ES6+)** - Interaktivitas dan animasi
- **Font Awesome** - Icon library

### 1. Navigation
- Menu navigasi yang sticky
- Mobile hamburger menu

### 2. Hero Section
- Pengenalan diri yang menarik
- Call-to-action buttons
- Abstract shapes animation

### 3. About Section
- Informasi tentang diri
- Statistics (Experience, Projects, Client Satisfaction)

### 4. Skills Section
- Web Development
- Graphic Design
- Responsive Design
- Database Management

### 5. Portfolio Section
- Showcase 3 project template

- Hover effects yang menarik

### 6. Contact Section
- Contact information
- Social media links
- Contact form dengan validasi

### 7. Footer
- Copyright information
